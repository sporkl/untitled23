# Untitled 23

Untitled 23 is an interactive, audience-driven sound world. Each participant's device outputs a different sound, driven by three global parameters that are collectively controlled by the entire audience.

This is the third incarnation of this piece, with a new backend built on OCaml 5, using the new effect system and multicore features.

Dependencies:
- dune
- piaf (development verison, use `opam pin add piaf https://github.com/anmonteiro/piaf.git`)
- eio
